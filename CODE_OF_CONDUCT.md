# Code of Conduct

## Our commitment

saas-blind-security is maintained by IbrahimCodeur and open to everyone. We want participation to be free of
harassment for everyone, regardless of age, body size, disability, ethnicity, gender identity and expression,
level of experience, nationality, appearance, race, religion, or sexual orientation.

## Expected behaviour

- Be respectful and constructive; assume good intent.
- Give and accept technical criticism graciously; focus on the problem, not the person.
- Practise responsible disclosure: report vulnerabilities privately (see [SECURITY.md](SECURITY.md)).
- Only test systems you are authorised to test; never use this project to attack others.

## Unacceptable behaviour

Harassment, insults, discriminatory language, personal attacks, doxxing or publishing others' private
information, sharing exploits against third parties' systems, and sustained disruption.

## Enforcement

Report incidents privately to the maintainer through GitHub (@IbrahimCodeur). Reports are handled
confidentially. The maintainer may remove content, warn, or ban contributors who violate this code.

## Scope

This code applies in all project spaces — issues, pull requests, discussions — and when representing the project.
